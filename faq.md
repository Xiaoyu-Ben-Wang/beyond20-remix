# Frequently Asked Questions

This page answers questions about **Beyond20 Custom Remix**, the unofficial fork. Most of what it does comes from Beyond20. There is a link to Beyond20's own FAQ at the end.

Use the newest version first. Your problem may already be fixed. The [changelog](Changelog) lists recent fixes and additions.

## About this fork

### What is Beyond20 Custom Remix?

It is a personal fork of [Beyond20](https://github.com/kakaroto/Beyond20), based on Beyond20 v2.21.0. Everything Beyond20 normally does still works. On top of that, it adds a **Roll20 quick roll launcher**. The launcher rolls a skill, saving throw or ability check from the Roll20 page, so you do not have to switch tabs. Try the [demo](demo), or look at the [Screenshots](screenshots) page.

### Is this the official Beyond20?

No. It is an unofficial fork. It is not connected to the Beyond20 project, D&D Beyond, Roll20 or Foundry VTT, and those projects do not support it. Bugs in this fork are not the upstream project's responsibility.

### How do I install it?

See the [Install](install) page. It is not in the Chrome Web Store or Firefox Add-ons on purpose. It is a personal fork, not a supported product.

If you have the official Beyond20 installed, turn it off first. Both extensions do the same job, so both would answer the same rolls.

### Does it cost anything?

No. It is free software under the GPL v3 license. There is nothing to buy. There is no account, no subscription and no advertising.

### Where do I report a bug or ask a question?

Use [this fork's issue tracker](https://github.com/Xiaoyu-Ben-Wang/beyond20-remix/issues). Report there, not upstream. One exception: if the problem also happens in the official Beyond20, use the [upstream issue tracker](https://github.com/kakaroto/Beyond20/issues).

### What information does it collect about me?

None. There is no analytics, no telemetry and no tracking. Nothing is sent to the author of this fork. The [Privacy](privacy) page has the full details, including the two optional exceptions.

### How do I turn the quick roll launcher off?

Open the extension's options. Go to the **VTT tab**. Untick **Show the quick roll launcher in Roll20**. There you can also switch the launcher and its panel between light and dark, and change the colour of their text and highlights.

### Will it get the upstream project's updates?

No, not automatically. It is a fork of one version. Upstream fixes must be added by hand, so this fork can fall behind. If you want the newest features and fixes, use the official Beyond20.

### Which browsers does it work on?

Chrome and other Chromium browsers (Edge, Brave, and so on), and Firefox. Every release has both builds.
