# Frequently Asked Questions

This page answers questions about **Beyond20 Custom Remix**, the unofficial fork. For everything it has in common with Beyond20 — which is most of it — there is a link to Beyond20's own FAQ at the end.

First of all, make sure you have the latest version, since some issues might have been recently fixed. You can also check out the [changelog](Changelog) for recent fixes or additions to the extension.

## About this fork

### What is Beyond20 Custom Remix?

It is a personal fork of [Beyond20](https://github.com/kakaroto/Beyond20), based on Beyond20 v2.21.0. Everything Beyond20 normally does still works; on top of that it adds a **Roll20 quick roll launcher** that lets you roll a skill, saving throw or ability check from the Roll20 page without switching tabs. See the [Features](features) page for the details and the [Screenshots](screenshots) page to see it.

### Is this the official Beyond20?

No. It is an unofficial fork and is not affiliated with or endorsed by the Beyond20 project, D&D Beyond, Roll20 or Foundry VTT. Bugs in this fork are not the upstream project's responsibility, and the upstream project cannot support this fork.

### How do I install it?

It is installed from source — see the [Install](install) page. It is deliberately not in the Chrome Web Store or Firefox Add-ons, because it is a personal fork rather than a supported product.

If you have the official Beyond20 installed from a store, disable it first. Both extensions do the same job and would otherwise both answer the same rolls.

### Does it cost anything?

No. It is free software, released under the GPL v3 license. There is nothing to buy, no account to create, no subscription and no advertising.

### Where do I report a bug or ask a question?

On [this fork's issue tracker](https://github.com/Xiaoyu-Ben-Wang/beyond20-remix/issues). Please report there rather than to the upstream project, unless you have confirmed the problem also happens with the official Beyond20, in which case the [upstream issue tracker](https://github.com/kakaroto/Beyond20/issues) is the right place for it.

### What information does it collect about me?

None. There is no analytics, no telemetry and no tracking, and nothing is sent to the author of this fork. The full details, including the two optional exceptions, are on the [Privacy](privacy) page.

### How do I turn the quick roll launcher off?

Open the extension's options, go to the **VTT tab** options, and untick **Show the quick roll launcher in Roll20**. There you can also switch the launcher and its panel between a light and dark theme, and change the colour of its text and highlights.

### Will it get the upstream project's updates?

Not automatically. It is a fork of one specific version, and upstream fixes have to be merged in by hand, so this fork can lag behind the official Beyond20. If you want the newest features and fixes as soon as they exist, use the official Beyond20 instead.

### Which browsers does it work on?

Chrome and other Chromium browsers (Edge, Brave, and so on), and Firefox. Both builds are in every release.
