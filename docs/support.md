# Support

## Getting help

Start with the [FAQ](faq). It answers most problems, and the upstream answers apply here too. The [Install](install) page explains how to install the extension.

This fork has no chat server and no mailing list. Ask on the [issue tracker](https://github.com/Xiaoyu-Ben-Wang/beyond20-remix/issues) instead, so the answer stays there for the next person.

## Reporting a bug

[Open an issue](https://github.com/Xiaoyu-Ben-Wang/beyond20-remix/issues/new) and include:

* what you did, what you expected, and what happened instead
* your browser and its version
* the extension's version (it is in the extension's popup and options page)
* which virtual tabletop you used — Roll20, Foundry VTT, or none
* whether the problem also happens with the official Beyond20, if you have tried it

If the problem also happens with the official Beyond20, it is an upstream bug. Report it on the [upstream issue tracker](https://github.com/kakaroto/Beyond20/issues).

## Known issues

## Official Beyond20

This fork only adds a Roll20 quick roll launcher to a project that already works well. For everything else — the store versions, the newest features, and the people who wrote most of this code — see the [official Beyond20 project](https://github.com/kakaroto/Beyond20).
